NITRO COAST — Free Original Arcade Racing Prototype
==================================================

HOW TO PLAY ON WINDOWS 10 / WINDOWS 11
-------------------------------------
1. Double-click NitroCoast.exe.
2. Your default web browser will open a LOCAL OFFLINE racing game.
3. Select a car and an environment; click START RACE.
4. Leave the tab open while you play. The launcher shuts down a short time after the tab is closed.

CONTROLS
--------
W or UP Arrow       Accelerate
S or DOWN Arrow     Brake
A / D or arrows     Steer
SPACE               Drift (earn score + refill nitro)
LEFT SHIFT          Nitro
P or ESC            Pause / resume
R                   Restart the current race
Gamepad             Steering / triggers / face buttons

INCLUDED CONTENT
----------------
- 3 selectable supercars (Falcon GT, Vortex X, Specter R)
- 3 unique road environments (Aurora Coast, Redline Canyon, Neon Overdrive)
- AI traffic and near-overpass score bonuses
- Nitro boost, drift physics, smoke, speed feedback, lap timer, results
- All environment and car artwork procedural, made in HTML Canvas; fully offline
- No account, launcher installation, paid assets, or external service required

NOTES
-----
This is an ORIGINAL indie arcade-racing demo inspired by the genre.
It is NOT a copy of The Crew Motorfest or any other copyrighted game.
Graphics are stylized pseudo-3D, not photorealistic AAA graphics.
A modern browser such as Microsoft Edge or Chrome is required.
The .exe is a small local HTTP server which contains the game and opens
it in the default web browser. It does NOT use the public internet.

If Windows SmartScreen warns about an unrecognized app, note this is an
unsigned locally generated executable. You can instead open index.html
from the source package directly in your browser (no executable needed).

The complete original source is supplied for study and modification.
