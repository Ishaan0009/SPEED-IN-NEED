# SPEED IN NEED

SPEED IN NEED is an independent arcade racing game for Windows.

## Latest release

[Download SPEED IN NEED Beta v0.5.3 (ZIP)](https://github.com/Ishaan0009/SPEED-IN-NEED/releases/download/v0.5.3/SPEED_IN_NEED_Beta_v0.5.3.zip)

Download and extract the ZIP, then open the included game folder. The package contains `SPEED_IN_NEED_v0.5.3.exe`, game data, and runtime dependencies. The public release omits `UserData` (player profiles, progress, and settings) and reports containing local installation paths.

For release details and older versions, visit the [Releases page](https://github.com/Ishaan0009/SPEED-IN-NEED/releases).
